# Storage Estimator
## Purpose

The Storage Estimator is a Python program that calculates the estimated storage required for a collection of photos, songs, and videos.

## How to Run the Program

1. Make sure Python is installed on your computer.
2. Open Command Prompt in the project folder.
3. Run the following command:

python storage_estimator.py

## Example Input and Output

Example input:

* How many photos? 10
* How many songs? 20
* How many videos? 2

Example output:

* Estimated storage needed: 1140 MB
* That is about 1.11 GB
